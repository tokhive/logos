# TokHive Logo Exports

Colors: Volt #C8F031 · Graphite #141517 · Paper #F2F2EE · Green on white #9CCB00  
Wordmark: Sora — Tok 300 / Hive 700 (Tok 500 for the all-green version on white)

## Marks (transparent background)
- `mark-volt` — for dark backgrounds, with horizontal cutouts
- `mark-graphite-volt` — for light or white backgrounds
- `mark-graphite` / `mark-white` — monochrome
- `mark-green-on-white` — all green on white

## Icons
- `app-icon-dark` / `app-icon-volt` — Bee client
- `avatar-dark` — GitHub and social profile avatar (circular)

## Lockups
- `lockup-dark` — for dark backgrounds
- `lockup-light` — for light backgrounds
- `lockup-green-on-white` — all green on white

Note: Text in the lockup SVGs references the Sora web font. Before sending files to print or using them offline, convert the text to outlines in Figma or Illustrator. PNGs are already rasterized and are not affected.
